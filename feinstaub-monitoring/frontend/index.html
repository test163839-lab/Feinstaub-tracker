Schnittstellen-Dokumentation für externe Handy-App

Die Smartphone-App sendet Messwerte des SPS-Geräts per HTTP-POST direkt an diesen Server:

POST /api/messung
Header: Content-Type: application/json
Minimaler JSON-Payload:
{
  "sps_id": "SPS-01",
  "latitude": 52.516842,
  "longitude": 13.388865,
  "pm1_0": 7.4,
  "pm2_5": 14.8,
  "pm4_0": 19.5,
  "pm10_0": 26.2,
  "temperature": 20.5,
  "humidity": 58.0,
  "pressure": 1013.25
}

💡 Tolerante Schnittstelle: Der Server akzeptiert für das Gerät sowohl sps_id, device_id als auch robot_id. Für Sensoren werden auch lat, lng, PM2.5, temp, hum, press akzeptiert.
